結語 — 為什麼 v3 結論被翻轉？

v3 → v1.5 結論之所以從「附條件通過」翻轉為「持有觀望」，並非分析方法改變，而是 4 個關鍵新事實的揭露：

  1. 江海 BBU 70% 獨家確認（v3 未知）→ 排除立隆 Rubin BBU 子賽道核心想像
  2. Q1 業外 -4.99 億揭露（v3 未知）→ 業外侵蝕從「可控」升至「致命」
  3. 股價基準從 178.5 上移至 234.5（+31.4%）→ 估值溢價從 +2% 升至 +34%
  4. 國際同業年報補查（v3 推估 → v1.5 實證）→ 立隆毛利優勢首次量化但江海規模超越風險浮現
v1.5 最終投資判讀 立隆電 2472 為「中等品質 + 高位估值 + 中高貓膩 🟠」的典型「持有觀望」標的。
本業 +11.1% YoY 強+ 家族治理穩定 + 毛利率全球前 5 大最高 三條長期支撐確保「永久迴避 4 條全不成立 → 長期可持有性」。
但八法溢價 +34% + 風險：優勢 9-10:1 + 江海 BBU 排除立隆 + 業外結構性風險上升 四條結構性壓力使主動進場不合理。
等回檔至 175-200 區間 + 3 進場條件任二成立後分批 + 部位上限 20-25% 為合理操作策略。
